# Políticas de Privacidade - Kanda Freelancer Bot

**Data de Vigência:** Janeiro de 2024

## 1. Informações que Coletamos

### 1.1 Dados do Utilizador
- ID do Telegram
- Nome de utilizador
- Mensagens de texto (apenas as que enviam ao bot)
- Hora e data de interações

### 1.2 Dados do Grupo
- ID do grupo
- Nome do grupo
- Timestamp de quando o bot foi adicionado

### 1.3 Dados de Moderação
- Avisos por publicação de links
- Registros de banimentos
- Razão dos banimentos

### 1.4 Dados de Anúncios
- Histórico de anúncios enviados
- Configuração de horários de envio

## 2. Como Usamos os Dados

- **Moderação**: Detectar e punir publicação de links não autorizados
- **Suporte**: Encaminhar mensagens privadas ao administrador
- **Melhorias**: Analisar padrões de uso para melhorar o bot
- **Segurança**: Manter histórico de ações para auditoria

## 3. Armazenamento de Dados

Todos os dados são armazenados em **Firebase Firestore**:
- Encriptação em trânsito (HTTPS)
- Servidores seguros do Google Cloud
- Backup automático

## 4. Compartilhamento de Dados

- ❌ **NUNCA** compartilhamos dados com terceiros
- ❌ **NUNCA** vendemos dados
- ✅ Apenas o administrador do bot tem acesso aos dados

## 5. Direitos do Utilizador

Você tem o direito de:
- Solicitar acesso aos seus dados
- Pedir remoção de seus dados
- Sair do grupo (dados mantidos para histórico de moderação)

Para exercer estes direitos, envie mensagem privada ao bot.

## 6. Segurança

Medidas de segurança implementadas:
- Variáveis de ambiente para credenciais
- Firestore com autenticação Firebase
- Sem armazenamento de senhas
- Validação de permissões antes de ações

## 7. Retenção de Dados

- **Avisos**: Mantidos indefinidamente para histórico
- **Banimentos**: Mantidos para poder revertê-los
- **Mensagens Privadas**: Até solicitação de remoção
- **Logs**: Até 90 dias (limpeza automática)

## 8. Conformidade

Este bot está em conformidade com:
- ✅ Termos de Serviço do Telegram
- ✅ GDPR (onde aplicável)
- ✅ Lei de Proteção de Dados Pessoais
